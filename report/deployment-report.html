Al-Merak Portal Project Overview & Executive Summary
Executive Summary

The Al-Merak Confirmation & Approval Portal is a fully operational, cloud-deployed web application designed to streamline the internal proposal submission and approval workflow. The system has been developed, tested locally, and successfully deployed to a production VPS server under the live domain confirmation.qomunix.com. It is now accessible 24/7 with SSL encryption and automated database management.

What Is This System?

The portal replaces manual, email-based approval processes with a structured digital workflow. It enables organizations to manage proposals end-to-end — from submission by a company representative to review and decision-making by designated managers and administrators — all within a single, secure web interface.

The platform supports multiple companies, multiple user roles, email notifications, activity tracking, and a full administrative dashboard, making it suitable for organizations that require traceable, auditable approval processes.

Al-Merak Portal Core Features & Modules
Key Features
👥

Role-Based Access Control

Three user roles — Super Admin, Manager, and Company User — each with distinct permissions and views to maintain data integrity and access security.

📋

Proposal Management

Company users submit proposals with detailed information. Proposals progress through defined stages: Pending → Under Review → Approved / Rejected.

✅

Multi-Level Approval Workflow

Managers review proposals via secure tokenized links sent by email. Decisions are recorded with comments and timestamps for full traceability.

🔔

Automated Email Notifications

The system sends automated emails at key workflow stages — proposal submission, review requests, and final decisions — via Hostinger SMTP.

🏢

Multi-Company Support

The platform supports multiple registered companies, each with their own users, proposals, and isolated data. Companies can be invited via email.

📊

Activity Log & Audit Trail

Every action — logins, submissions, approvals, rejections — is recorded with the acting user and timestamp, providing a complete audit trail.

🔒

JWT Authentication

Secure token-based authentication with access and refresh tokens. Sessions expire automatically and tokens are blacklisted on logout.

💻

Admin Dashboard

Super Admins have access to a comprehensive dashboard showing system-wide statistics, user management, company oversight, and full proposal history.

Al-Merak Portal Security & Testing
Security Measures Implemented
🔒
HTTPS / SSL
All traffic encrypted via TLS 1.2/1.3 with Let's Encrypt certificates
🔑
JWT Auth
Short-lived access tokens + refresh rotation with token blacklisting on logout
🛠
CORS Policy
API only accepts requests from the authorized frontend domain
👤
Role Permissions
Every API endpoint enforces role-based access — no privilege escalation possible
🔄
Review Tokens
Tokenized proposal review links expire after 14 days — single-purpose, time-limited
📋
Audit Trail
All actions are logged with user identity and timestamp — full accountability
🚫
Non-Root Container
Production containers run as non-root system users to limit attack surface
🔢
Env Isolation
All secrets stored in server-side environment variables — never in source code
✅
Password Validation
Django's built-in validators enforce strong password policies for all accounts
